# Логотип MebelGrid

Знак — открытый угол корпуса: янтарная верхняя плита, янтарная левая панель и синяя передняя панель со светлой окантовкой и белыми маркерами по углам. Шрифтовая часть — «MebelGrid» плотной геометрической гарнитурой, переведённая в кривые; внешних шрифтов в SVG нет.

Оба файла рассчитаны на тёмный фон. Компоновка собирается из них в разметке: в шапке знак и надпись стоят в ряд, на экране запуска — друг под другом.

## Файлы

| Файл | Назначение |
| --- | --- |
| `mebelgrid-mark.svg` | Знак для шапки, экрана запуска и favicon. |
| `mebelgrid-wordmark.svg` | Надпись MebelGrid: «Mebel» белым, «Grid» янтарём. |

## Правила использования

- Минимальная высота знака — 20 px, надписи — 12 px по высоте заглавных.
- Свободное поле вокруг логотипа — не меньше половины высоты знака.
- Не меняйте пропорции, не наклоняйте, не перекрашивайте панели по отдельности, не убирайте маркеры и окантовку.
- На светлом фоне используйте только знак: янтарная плита и белые маркеры без подложки теряются.
