# Логотип PLIT 3D

Знак — три изометрические панели в стопке: серая сверху, янтарная в середине, бирюзово-синяя снизу. Панели рисуются снизу вверх, поэтому верхняя перекрывает нижнюю. У каждой панели градиент на верхней плоскости, свои грани по толщине, блик и янтарные отсветы от центральной панели. Шрифтовая часть — «PLIT3D» плотной геометрической гарнитурой, переведённая в кривые; внешних шрифтов в SVG нет.

Оба файла рассчитаны на тёмный фон. Компоновка собирается из них в разметке: в шапке знак и надпись стоят в ряд, на экране запуска — друг под другом.

## Правила использования

- Минимальная высота знака — 20 px, надписи — 12 px по высоте заглавных.
- Свободное поле вокруг логотипа — не меньше половины высоты знака.
- Не меняйте пропорции, не наклоняйте, не перекрашивайте панели по отдельности, не убирайте блик и свечение средней панели.
- На светлом фоне используйте только знак на тёмной подложке: светлая верхняя панель без неё теряется.
